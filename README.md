# FreshTrack

## Overview

FreshTrack is a smart food management application designed to reduce household food waste. The application allows users to track groceries, monitor expiry dates, receive reminders, and discover recipes based on available ingredients.

## Features

### Food Tracking
- Add groceries manually
- Track expiry dates
- Monitor food quantity
- Hybrid scan (Option to scan or manually enter product, perhaps have NIP scanning)

### Expiry Notifications
- Countdown timers (integrate as a calendar) 
- Reminders before food expires
- Suggestions for using ingredients

### Recipe Suggestions
- Find recipes based on available food
- Filter recipes by time and nutrition
- Link external recipes
- When finding recipes checks to see if all ingredients are available, if not check which one is needed and add to shopping list
- Filterable recipes (e.g nutrition, macros, calories, ingredients, time)

### Shopping List
- Add ingredients needed for recipes
- Track required groceries
- Analyse trends in groceries and create the following weeks list (based off liked recipes and suggestions)

### Dashboard
- Seasonal food recommendations
- Food facts (storage recomendations)
- Expiry summaries
- Food logging (cal counter, macros counter)
